# Git roles:

- git clone githubRepositoryLink
- git switch main: to main sure you are in main branch
- git pull origin main: to pull all the changes to main
- git switch -c branchName : to create a new branch
- git switch branchName : to go to this branch already exist
- git status: see files that you modified
- git branch: see your branches and which one you are in
- git add . : to add all the modifications in project
- git commit -m "title..." : to store modifications as copy
- git push origin branchname : to move work from commit to github
